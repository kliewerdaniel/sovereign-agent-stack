# Authority Escape Graph

> **Status:** Post-Integration Audit
> **Last Updated:** 2026-09-09
> **Phase:** Runtime Authority Closure

This document enumerates every consequential entry point in the Sovereign Agent Stack and traces its authority path. The goal is to ensure that **every consequential effect has a reconstructible authority path from sovereign root to external effect**.

---

## Consequential Entry Points

### 1. Quant Research Orchestrator → Broker

| Attribute | Value |
|-----------|-------|
| **Entry** | `QuantResearchOrchestrator.run()` |
| **Consequence** | Order submission to broker (simulated or live) |
| **Authority Source** | `AuthorizationArtifact` derived from `ResearchDecision` |
| **Capability** | `ExecutionCapability` materialized by orchestrator |
| **Executor** | `CapabilityBoundBroker` |
| **Receipt** | `ExecutionReceipt` generated by broker |
| **Provenance** | `ProvenanceGraph` with authorization/capability/receipt nodes |
| **Direct Invocation?** | No — raw `BrokerAdapter` is wrapped |
| **Executor Substitution?** | No — capability bound to specific executor |
| **Resource Substitution?** | No — capability bound to specific symbol |
| **Replay Possible?** | No — single-use nonce + replay store |
| **Temporal Extension?** | No — capability has expiration |
| **Domain Crossing?** | No — domain-checked |
| **Post-Restart?** | Replay protection is durable |
| **Reconstructible?** | Yes — from `ProvenanceGraph` |
